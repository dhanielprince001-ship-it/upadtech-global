# UPADTECH GLOBAL LTD website

## Run locally
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm run dev`.

## Deploy
Push this folder to GitHub and import the repository into Vercel.
Vercel build command: `npm run build`
Output directory: `dist`
